# Верити — мод для Minecraft (Fabric 1.21.1)

Круглая помощница, которая отвечает на вопросы в чате через Gemini.

## Сборка
Нужны Java 21 и интернет.
    gradle wrapper --gradle-version 8.10
    ./gradlew build
Готовый мод: build/libs/verity-1.0.0.jar → положить в mods/ (нужны Fabric Loader и Fabric API).

## Настройка
Запустите игру один раз, откройте config/verity.json и впишите apiKey
(или задайте переменную окружения GEMINI_API_KEY). Ключ: https://aistudio.google.com/apikey

## Использование
Призовите Верити яйцом из креатива (вкладка «Яйца призыва»), встаньте рядом (до 24 блоков)
и напишите в чат: «Верити, как сделать зелье?». Пока она отвечает, открывает рот.
Если answerAllNearby = true, отвечает на любое сообщение рядом.

## Коробка Верити
Предмет «Коробка Верити» (вкладка «Функциональные блоки» в креативе). Кликни ей по земле, и Верити выскочит из коробки.
Крафт: бумага по кругу (8 шт.) + слизь в центре.

## Действия по просьбе
Верити умеет по просьбе в чате: выдать предметы («Верити, дай 10 алмазов»), призвать мобов («заспавни 3 коров»)
и построить («построй дом из камня»: house, tower, wall, platform, pyramid).
По умолчанию это доступно только операторам. Лимиты и запреты настраиваются в config/verity.json
(actionsEnabled, allowActionsForAll, maxItems, maxMobs, maxBuildSize, maxBlocks, bannedMobs).

## Как получить .jar без установки Java (через GitHub)
1. Создайте репозиторий на github.com и загрузите в него содержимое папки verity-mod (вместе со скрытой папкой .github).
2. Откройте вкладку Actions, дождитесь зелёной галочки у запуска «build».
3. Откройте запуск, внизу в «Artifacts» скачайте verity-mod. Внутри будет verity-1.0.0.jar (файл без -sources).
4. Положите его в папку mods. Нужны Minecraft 1.21.1, Fabric Loader и Fabric API.
